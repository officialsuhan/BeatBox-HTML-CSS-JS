# 🎧 BeatBox — Music Player

**BeatBox** is a modern, browser-based music player built using HTML, CSS, and JavaScript. It features a sleek interface, playlist management, and interactive playback controls for an enjoyable music-listening experience.

## ✨ Features

- 🎵 **Music Playlist** — Browse and play tracks from the music library.
- ▶️ **Playback Controls** — Play, pause, skip to the next track, or return to the previous track.
- 🔊 **Volume Control** — Adjust the audio volume.
- 📊 **Progress Bar** — View and control playback progress.
- 🔍 **Search** — Find tracks quickly.
- ❤️ **Favorites** — Keep track of favorite songs.
- 🔀 **Shuffle & Repeat** — Customize playback.
- 🕘 **Recently Played** — Keep track of recently played songs.
- 📱 **Responsive Design** — Enjoy the interface on desktop and mobile screens.
- 💾 **Local Storage** — Save supported preferences between visits.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start exploring the music player!

No build tools are required for basic local use.

## 🎯 Project Goal

BeatBox was created to practice front-end web development, JavaScript event handling, audio playback controls, DOM manipulation, and responsive UI design.
